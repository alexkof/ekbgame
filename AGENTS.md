# Заметки для агентов (Codex и др.)

Проект — веб-игра про Екатеринбург (TypeScript + Vite, карта на Canvas 2D). Подробные правила —
[CLAUDE.md](CLAUDE.md), они действуют и для тебя:

- Язык проекта, интерфейса, документации и сообщений коммитов — русский. Код и
  идентификаторы — английский.
- Перед коммитом кода: `npm run check` (prettier, tsc, vitest) должен проходить.
- Одна ветка `main`; каждый push в неё публикуется на https://alexkof.github.io/ekbgame/.

## Рисунки зданий

Если тебя просят нарисовать здания, выполнить задание из `art/tasks/…` или «сделать рисунки
квартала» — открой файл задания в [`art/tasks/`](art/tasks/) и делай ровно то, что в нём
написано. Коротко:

- входы для здания `<id>`: `art/<id>/guide.png` (каркас — первой картинкой), фото из
  `art/<id>/photos/`, образец стиля `art/style-ref.png` (если есть), запрос `art/<id>/prompt.txt`;
- результат — PNG размера каркаса (`art/<id>/frame.json` → `size`) в `art/<id>/drawn/`:
  `python3 scripts/art/generate.py <id>` (нужен `OPENAI_API_KEY`) или встроенным генератором
  изображений с теми же входами;
- больше ничего не меняй: модели (`src/map/data/models/`), каркасы, запросы, `info.json` и код
  трогать не нужно. Рисунок на карту ставит CI после попадания коммита в `main`
  (`.github/workflows/art.yml`).

Методика целиком — [docs/ART.md](docs/ART.md).
