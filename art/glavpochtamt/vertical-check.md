# Проверка вертикалей Главпочтамта — 2026-11-01

Причина повторного наклона — старый рисунок `pilot-20261101.png`, созданный по кадру
с `camera.lean = 0.24`. При неизменной геометрии карта продолжала показывать его после
перехода на `lean = 0`. Изменение камеры исправило модели, но не готовые пиксели.

Новый рисунок `drawn/upright-20261101.png` создан по текущему `guide.png`; исходный кадр
сохранён рядом в `.frame.json`. Фото использовалось для деталей фасада, не для ракурса.

Проверены прямые участки контрастных рёбер (координаты в пикселях, начало слева сверху).
Поиск отрезков Canny + Hough подтверждён просмотром изображения. Короткие отклонения
на 1 пиксель у сглаженных краёв окон не считаются наклоном всего фасада.

Диагонали кровли и основания вдоль бокового крыла — линии глубины; они остаются наклонными.

От повторения защищают обязательный исходный кадр при импорте, запрет наклона при
совмещении, проверка камеры/масштаба высот/геометрии перед показом рисунка и тесты.
При следующей генерации нужно повторить проверку именно нового изображения:
правильные метаданные сами по себе не гарантируют правильных линий внутри PNG.
