# Рисунки зданий

Здания на карте рисуются картинками: художник или генератор изображений (ChatGPT и т. п.)
рисует здание поверх **каркаса** — 3D-модели в проекции карты, — а движок ставит рисунок на
карту пиксель в пиксель. Модель строится из OpenStreetMap и остаётся промежуточным шагом.
Методика и решения — [docs/ART.md](../docs/ART.md).

## Квартал целиком — через Codex

Задания лежат в [`tasks/`](tasks/): например, [`tasks/sevastyanov.md`](tasks/sevastyanov.md) —
квартал Дома Севастьянова и Главпочтамта. Codex читает [`AGENTS.md`](../AGENTS.md) и сам
находит задание. Скажите ему:

1. «Выполни этап 1 из `art/tasks/sevastyanov.md`» — нарисует главные здания и остановится.
2. Посмотрите рисунки и скажите: «Сделай рисунок `art/glavpochtamt/drawn/…` образцом стиля».
3. «Выполни этап 2 из `art/tasks/sevastyanov.md`» — остальные здания в том же стиле.
4. Codex коммитит сразу в `main` — через пару минут рисунки встанут на карту сами.

Codex рисует скриптом `scripts/art/generate.py` через OpenAI API: в настройках его окружения
нужны переменная `OPENAI_API_KEY` и доступ в интернет к `api.openai.com`. Если ключ задан как
секрет и скрипт его не видит, задайте его обычной переменной окружения. Если у Codex есть свой
генератор изображений, он может обойтись без ключа.

## Как нарисовать здание вручную

1. Откройте папку здания (список ниже). В её README — каркас, готовый запрос и ссылки на фото.
2. В ChatGPT приложите каркас `guide.png` **первым**, затем 1–3 фото здания, вставьте запрос.
3. Скачайте результат и загрузите в папку `drawn/` этого здания на GitHub
   (Add file → Upload files → Commit changes в `main`).
4. Через пару минут рисунок встанет на карту (https://alexkof.github.io/ekbgame/), а в папке
   здания появится `check.jpg` — проверка совмещения с каркасом.

Не понравилось — загрузите новый вариант: на карту встаёт последний добавленный рисунок.
Чтобы вернуть один из прежних, укажите его в `info.json` здания: `"use": "drawn/имя.png"`.

## Фото

- Свои фото и фото со свободной лицензией (Викисклад, с автором и лицензией в имени файла
  или в `info.json`) можно класть в `photos/` здания.
- Чужие фото без свободной лицензии (панорамы, сайты) в репозиторий не кладём — репозиторий
  публичный. Их можно просто приложить в ChatGPT.

## Новое здание

Попросите Claude или сделайте сами (нужны Python с `scripts/map/requirements.txt`, Node.js и
Playwright):

```bash
python scripts/map/osm_tool.py find 56.8391 60.6061 40        # id контура в OSM
python scripts/map/osm_tool.py building w51503505 --id sevastyanov-house --kind civic
python scripts/art/art.py prepare sevastyanov-house             # каркас, запрос, ссылки на фото
```

Перед каркасом модель стоит сверить с фото и дополнить тем, что определяет силуэт: башни,
купола, шпили, высокие крыши (`src/map/data/models/<id>.json`). Общий стиль для всех
запросов — [`style.txt`](style.txt).
